## 二、考察了什么能力（能力模型）

### 1. 计算机基础与语言运行时
- 堆 / 栈 / 方法区正确概念（纠正口语笔误）
- JMM：`volatile` / `synchronized` / CAS
- 集合与字符串实现差异

### 2. 数据层设计与调优
- B+ 树索引、最左前缀、执行计划
- 隔离级别、MVCC、锁与死锁
- 批量写入、去重 upsert、慢 SQL 闭环

### 3. 分布式与一致性工程
- Cache-Aside、击穿/穿透/雪崩
- MQ 出箱/事务消息与消费幂等
- 支付状态机、对账、最终一致（BASE）
- CAP 的工程化理解（而非背诵口号）

### 4. 框架与中间件熟练度
- Spring IoC/AOP/事务代理边界
- 线程池参数与风险（无界队列）
- Redis 锁与持久化
- 微服务注册配置、负载、熔断
- Nginx、S3/OBS、ES

### 5. 安全与合规意识
- XSS 输出编码 + CSP；SQLi 参数化（写清所在层）
- 加密检索用盲索引/HMAC，禁止解密全表
- S3 服务端加密与 KMS；原文「RES」纠正为 AES
- 对接签名、防重放、密钥管理

### 6. 国产化 / 信创迁移能力
- 类型与函数差异、空串与 NULL、层次查询改写
- 迁移校验与切换窗口
- 国产中间件替换与验证

### 7. 可观测性与排障
- 用证据区分代码 / SQL / GC / 下游
- 工具链：慢日志、EXPLAIN、jstack/MAT、APM

### 8. 工程协作与领导力表达
- 评审、辅导、重构策略、无文档熟悉项目
- STAR 讲述业务难点

## 三、重点如何培养（结合分布的行动清单）

### A. 高权重：事务 · 并发 · 数据库（约 47 题量级）
1. **每周精读**：Spring Transaction 传播表 + 自调用实验（写可运行 demo）。
2. **强制习惯**：上线 SQL 必看 EXPLAIN；整理「索引失效」个人清单对照生产。
3. **并发**：手写/精读 `ThreadPoolExecutor` 状态机；`CountDownLatch`/`CF.allOf` 完成协调；JCIP 选读可见性与锁章节。
4. **对照官方**：MySQL 隔离与锁、openGauss/PG 默认 RC 差异表做成自己的速查卡。

### B. 高权重：缓存 · MQ · 一致性
1. 画清「穿透/击穿/雪崩」决策树；实现一个带单飞锁的 Cache-Aside demo。
2. 实现 Outbox + 幂等消费者最小示例；理解 at-least-once。
3. Redis：`SET NX EX` + Lua 解锁；读官方 distributed locks 说明与边界。

### C. 信创迁移（18 题）
1. 建立 **Oracle → openGauss** 类型/函数/分页/层次查询对照表（只收官方文档条目）。
2. 做一次「行数 + 金额聚合 + 抽样哈希」迁移校验演练。
3. 区分「兼容模式」与「可上线」：用失败 SQL 列表驱动改造。

### D. JVM 与排障（13+4）
1. 记住：**JDK8 默认 Parallel（服务器类常见） / JDK9+ 默认 G1**，并用本机 `PrintFlags` 验证。
2. 练：制造小泄漏 → dump → MAT 找 Dominator Tree。
3. 建立慢接口五层清单：网关 / 应用 / SQL / 缓存 / 下游。

### E. 安全（不可降级）
1. XSS：只在**输出**按上下文编码；配 CSP；富文本白名单。
2. SQLi：DAO 层 PreparedStatement / `#{}`；禁止关键字黑名单当主防。
3. 手机号检索：HMAC 盲索引列或 ES keyword；明文后四位是否落库先做合规评估。
4. S3：SSE-KMS；密钥在 KMS 不在桶内明文。

### F. 微服务与工程软技能
1. Feign + LoadBalancer 策略实验；Sentinel/Resilience4j 熔断半开观察。
2. Nacos 配置 `@RefreshScope` 边界（哪些不能热更）。
3. 准备 2 个 STAR 故事（迁移难点、线上事故）可被追问到指标。

## 四、学习资源优先级（与 references.md 对齐）

1. **第一优先**：Oracle/MySQL/openGauss/Redis/Spring **官方文档** + JVM Spec / GC Tuning。  
2. **第二优先**：*Effective Java*、*JCIP*、OWASP Cheat Sheets、AWS S3 加密指南。  
3. **第三优先**：CAP/BASE 经典文章（Brewer；Gilbert & Lynch；Pritchett）、GoF 策略/工厂、Fowler 重构。  
4. 论文与教材以 `references.md` 为准，**不引用无法核验的二手「伪论文」**。

## 五、面试表达建议（针对本套题）

- **先结论后机制**：核心结论一句，再展开边界。  
- **带版本与产品**：默认隔离级别、默认 GC、AOF 是否默认开启。  
- **主动纠错**：堆/栈 LIFO、RES→AES，体现严谨。  
- **安全题写层次**：XSS 在输出/CSP；SQLi 在 DAO 参数化。  
- **一致性题给模型**：权威数据源是谁、失败怎么补偿、如何对账。
