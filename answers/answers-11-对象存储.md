### Q127（原始编号: 6）

**【题干】**
亚马逊简单存储服务（Amazon S3）存储桶，你处理一些文件后，处理了哪些源数据，处理了哪些对象，容器一共有哪些源数据和对象，你又是分别怎么处理的？你是怎么对接并且调用的？

**【核心结论】**
S3 核心是桶（Bucket）与对象（Object，含 Key、数据、元数据）。系统元数据（Content-Type、Content-Length 等）与用户元数据（x-amz-meta-*）分开；对接用 AWS SDK（Put/Get/Delete/List、预签名 URL）。

**【详细说明】**
处理：
- 对象：上传/下载/删除/拷贝、分片上传大文件。
- 元数据：内容类型、缓存控制、自定义业务 ID。
- 访问：IAM、桶策略、预签名。
「容器」口语常指 Bucket。

**【示例/写法】**
s3.putObject(bucket, key, file);
s3.generatePresignedUrl(...);

**【易错点】**
- 把元数据当可检索主库（应用仍需索引）。

**【权威依据】**
- AWS S3 用户指南：对象与元数据、SDK

### Q128（原始编号: 8）

**【题干】**
亚马逊简单存储服务（Amazon S3）存储桶比较核心的要点是什么？

**【核心结论】**
要点：桶与对象模型、区域、一致性模型、权限（IAM/桶策略/ACL）、加密、版本控制、生命周期、耐用性与成本存储类、命名与键设计。

**【详细说明】**
展开 5–6 个要点即可；强调最小权限与加密默认。

**【示例/写法】**
开启 Block Public Access；默认 SSE；生命周期转 IA。

**【易错点】**
- 公有桶误配。

**【权威依据】**
- AWS S3 最佳实践与安全文档

### Q129（原始编号: 180）

**【题干】**
对象存储服务（Object Storage Service，OBS）容器。

**【核心结论】**
OBS 通常指云厂商对象存储（如华为云 OBS），概念对齐 S3：桶/容器 + 对象 + 元数据 + SDK/API；注意厂商 API 差异与权限模型。

**【详细说明】**
对接：终端节点、AK/SK 或 IAM 角色、SDK 上传下载、生命周期与加密。

**【示例/写法】**
对比一句 S3 兼容性（若使用兼容协议）。

**【易错点】**
- 与块存储/文件存储混淆。

**【权威依据】**
- 华为云 OBS 产品文档（或对应厂商 OBS 文档）
