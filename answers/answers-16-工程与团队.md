### Q141（原始编号: 13）

**【题干】**
Nginx 用过吧，怎么用的？

**【核心结论】**
反向代理、负载均衡、静态资源、TLS 终结、限流、缓存；配置 server/location、upstream。

**【详细说明】**
项目：前端静态 + API 反代；灰度；gzip。

**【示例/写法】**
upstream backend { server a; server b; }
location /api/ { proxy_pass http://backend; }

**【易错点】**
- 不配超时导致雪崩。

**【权威依据】**
- Nginx 官方文档：ngx_http_proxy_module

- 只给差评不给路径。

**【权威依据】**
- 工程管理通识；代码评审实践

### Q146（原始编号: 35, 185）

**【题干】**

**【核心结论】**

**【易错点】**
- 无测试全面重写。

**【权威依据】**
- Fowler《重构》；绞杀者应用模式

### Q148（原始编号: 96, 105）

**【题干】**
Excel 文件处理，你用的是哪个类库？怎么使用？介绍一种使用方式。另外，Apache POI 和 EasyExcel 有什么区别？什么情况下使用哪个？

**【核心结论】**
POI 功能全但大文件易占内存；EasyExcel（或流式方案）基于SAX/流式读写更省内存，适合大导出导入。小文件随便，大文件优先 EasyExcel。

**【详细说明】**
EasyExcel：监听器按行读；注解映射。POI：XSSF/SXSSF（SXSSF 也可流式写）。

**【示例/写法】**
EasyExcel.read(file, Dto.class, listener).sheet().doRead();

**【易错点】**
- 百万行用 XSSF 一次性读爆内存。

**【权威依据】**
- Apache POI 文档；EasyExcel 官方文档

### Q150（原始编号: 181）

**【题干】**
Linux 操作系统常用命令。

**【核心结论】**
分类：文件（ls/cd/cp/mv/rm/tar）、查看（cat/less/tail/grep/find）、进程（ps/top/htop/kill）、网络（ss/netstat/curl）、磁盘（df/du/iostat）、权限（chmod/chown）、日志与journal。

**【详细说明】**
运维排障组合：top → 找 PID → jstack/绝对路径日志 tail -f。

**【示例/写法】**
ss -lntp; tail -n 100 -f app.log; journalctl -u service

**【易错点】**
- rm -rf 误用。

**【权威依据】**
- man 手册；Linux 文档项目
