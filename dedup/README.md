# 面试题去重分类结果

本目录是对原始 **239** 道 Java/后端面试题（含大量重复）的完整去重与分类整理。

## 文件说明

| 文件 | 用途 |
|---|---|
| `README.md` | 本说明 |
| `toc-counts.txt` | 统计与分类计数（快速扫一眼） |
| `01-deduped-by-category.md` | **主文件**：按分类列出全部唯一题，含完整题干与原始编号 |
| `02-number-to-canonical.md` | **审计表**：1→239 每题映射到规范题 ID/分类/完整题干 |
| `03-coverage-checklist.md` | **覆盖证明**：逐号 ✅，并列出所有合并组 |

## 怎么用

1. 复习/刷题：打开 `01-deduped-by-category.md`，按分类看唯一题。
2. 核对原文某一条（如第 173 题）去哪了：打开 `02-number-to-canonical.md` 搜编号。
3. 证明没有漏题：打开 `03-coverage-checklist.md`，确认 239/239。

## 去重原则

- 语义相同或仅措辞微调（如「缓存击穿的原因以及解决办法」与「缓存击穿的原理及解决办法」）合并为一题。
- 合并后保留**最完整**的题干作为规范文本。
- 所有被合并的原始编号都会写在规范题旁，不会静默消失。
- 原文中的「第2部分：第81—160条」「第3部分：第161—239条」用于对齐 1–239 编号。
