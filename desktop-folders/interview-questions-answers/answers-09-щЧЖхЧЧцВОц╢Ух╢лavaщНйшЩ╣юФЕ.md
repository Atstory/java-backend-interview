### Q113（原始编号: 39, 232）

**【题干】**
队列和栈的区别。

**【核心结论】**
队列 FIFO（先进先出）；栈 LIFO（后进先出）。用途：队列缓冲/BFS；栈递归/DFS/括号匹配。

**【详细说明】**
实现：数组/链表；Java 中 Queue/Deque、Deque 作栈优于遗留 Stack 类。

**【示例/写法】**
queue.offer/poll; deque.push/pop

**【易错点】**
- 混淆 FIFO/LIFO。

**【权威依据】**
- 数据结构教材；java.util.Deque

### Q114（原始编号: 40, 231）

**【题干】**
栈和堆分别有什么作用？堆涉及的先进后出概念，能举个例子吗？

**【核心结论】**
按正确 CS 定义：栈（数据结构）LIFO；JVM 堆存放对象实例，与「先进后出」无关。原文将「堆」与 LIFO 关联属于笔误/口误，应纠正为「栈」才是先进后出。

**【详细说明】**
**纠正说明**：先进后出是**栈**的性质，不是堆。
- 数据结构栈：方法调用、撤销、DFS。
- JVM 堆：对象、数组；GC 管理。
- JVM 栈：每线程栈帧、局部变量。
示例（栈 LIFO）：浏览器后退栈；函数调用返回。

**【示例/写法】**
调用 f→g→h，返回 h→g→f（栈）。
堆：new Object() 在堆上分配。

**【易错点】**
- 跟着口述把堆说成 LIFO。
- 混淆「数据结构堆(heap 优先队列)」与「JVM 堆」。

**【权威依据】**
- 数据结构教材（栈）；JVM Spec 堆与栈

### Q115（原始编号: 53, 171）

**【题干】**
讲一下堆和栈的区别，分别存储什么？

**【核心结论】**
JVM：堆存对象实例与数组（共享）；栈存栈帧（局部变量、操作数栈等，线程私有）。生命周期与大小特征不同。

**【详细说明】**
补充：静态变量与类元数据在方法区/元空间；小对象标量替换等优化例外不展开。

**【示例/写法】**
局部 int 在栈帧；User u=new User() 引用在栈、对象在堆。

**【易错点】**
- 说基本类型一定只在栈（字段在对象内则随堆）。

**【权威依据】**
- JVM Spec Runtime Data Areas

### Q116（原始编号: 54, 170）

**【题干】**
String 字符串存在哪里，堆还是栈？

**【核心结论】**
String 对象在堆上；字面量通常在堆的字符串常量池（JDK7+ 池在堆）。局部变量中的引用存在栈帧。

**【详细说明】**
intern 行为；不可变；拼接可能产生新对象。

**【示例/写法】**
String s = "hi"; // 引用在栈，对象在池/堆

**【易错点】**
- 说 String 整段在栈。

**【权威依据】**
- JVM 与 JLS String；OpenJDK 字符串池说明

### Q117（原始编号: 73, 113）

**【题干】**
StringBuilder 和 StringBuffer 的区别。

**【核心结论】**
二者均可变字符序列；StringBuffer 方法同步线程安全；StringBuilder 无同步更快，适合单线程。现代单线程拼串用 StringBuilder 或 +（编译器优化）。

**【详细说明】**
API 类似 append/insert；初始容量可避免扩容。

**【示例/写法】**
StringBuilder sb = new StringBuilder(64);

**【易错点】**
- 多线程共享 Builder。

**【权威依据】**
- StringBuilder/StringBuffer Javadoc

### Q118（原始编号: 77）

**【题干】**
Map 的底层有哪些组成部分？

**【核心结论】**
以 HashMap 为例：数组 table + 链表/红黑树节点；关键字段 capacity、loadFactor、threshold、size；hash 扰动与扩容。

**【详细说明】**
JDK8：冲突拉链，树化阈值；树退化。ConcurrentHashMap 结构不同。

**【示例/写法】**
说明 put 流程：hash → 下标 → 冲突处理 → 扩容。

**【易错点】**
- 仍说 JDK8 HashMap 只有链表。

**【权威依据】**
- HashMap Javadoc/源码；Effective Java hashCode

### Q119（原始编号: 143）

**【题干】**
创建对象的几种方式。

**【核心结论】**
new、反射、克隆、反序列化、Unsafe/allocateInstance（特殊）等；工厂与依赖注入是创建模式而非 JVM 原语。

**【详细说明】**
各方式是否调用构造：反序列化/clone 有特殊规则。

**【示例/写法】**
clazz.getDeclaredConstructor().newInstance();

**【易错点】**
- 把 Spring getBean 当成 JVM 创建指令级方式而不区分。

**【权威依据】**
- Java Language Spec；Object.clone；Serialization
