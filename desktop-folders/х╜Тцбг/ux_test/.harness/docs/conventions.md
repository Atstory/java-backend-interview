# 通用规范

## 命名规范
- 目录命名规则
- 文件命名规则
- 变量命名规则
- 方法命名规则
- 组件或模块命名规则

## 目录规范
- 什么文件放哪里
- 什么文件不允许放在业务目录
- 临时文件如何处理

## 配置规范
- 配置如何分层
- 敏感配置如何处理
- 环境差异如何管理

## 错误处理规范
- 错误如何抛出
- 错误如何记录
- 错误如何向上游返回

## 日志规范
- 记录什么
- 不记录什么
- 日志字段是否统一

## 注释规范
- 什么情况必须写注释
- 什么情况不要写废话注释
- 注释应描述什么信息

## 提交规范
- commit 信息格式
- 一个提交应只做一类事情
- 禁止把无关改动混进同一个提交
