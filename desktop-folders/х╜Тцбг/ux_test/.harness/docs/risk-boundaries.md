# 风险边界

## 高风险目录
- 配置目录
- 部署脚本目录
- 数据迁移目录
- 公共基础模块目录
- 鉴权、计费、库存、订单等关键模块目录

## 高风险操作
- 批量删除
- 批量更新
- 修改核心配置
- 修改发布流程
- 修改数据库结构
- 修改公共接口契约
- 修改安全相关逻辑

## 必须人工确认的动作
- 影响生产数据的操作
- 影响外部接口兼容性的操作
- 影响权限、安全、计费的操作
- 影响发布流程的操作

## 回滚要求
- 变更前必须有回滚路径
- 回滚步骤必须可执行
- 无法快速回滚的变更必须提前说明

## 发布前检查项
- 影响范围是否明确
- 风险是否明确
- 测试是否完成
- 未覆盖项是否明确
- 回滚方案是否明确
