Codex Config Forge

把 MCP JSON 直接锻造成 Codex 配置

输入服务名和 JSON 配置，页面会自动转换成 Codex 可直接使用的 TOML 片段。支持单个服务对象、整组服务对象、以及包含 mcpServers / mcp_servers 的完整 JSON 结构。

输入形态 单对象 / 多对象
输出形态 TOML 片段
快捷能力 一键复制
支持规则

为了避免只支持示例，我把转换逻辑做成了通用版：

  • 如果你粘贴的是单个服务对象，就使用上方“服务名”作为表头。
  • 如果你粘贴的是多服务对象，会自动按 key 生成多个 [mcp_servers.xxx] 区块。
  • env 会自动转成 TOML 内联表，数组会自动转成 TOML 数组。
  • 如果服务名含空格或特殊字符，会自动清洗成安全 key。
