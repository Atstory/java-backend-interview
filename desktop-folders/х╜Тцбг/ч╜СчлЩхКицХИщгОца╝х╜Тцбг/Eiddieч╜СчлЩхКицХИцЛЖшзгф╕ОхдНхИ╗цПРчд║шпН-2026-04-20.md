# Eiddie 网站动效拆解与复刻提示词

## 1. 分析对象

- 站点：`https://www.eiddie.me/`
- 公开仓库：`https://github.com/eiddiedev/eiddie-universe`
- 分析日期：`2026-04-20`

说明：
本结论基于站点公开页面信息与公开仓库 `index.html`、`styles.css`、`script.js` 的实现方式整理而成。个别运行时表现未做本地逐帧录制，但从源码结构可以较高置信度确认其动效机制。

## 2. 一句话结论

这不是一个依赖重型动画框架的作品集站点，而是一个以 `Vite + HTML + CSS + Vanilla JS` 为主体、辅以 `Peel.js` 做首屏翻页贴纸效果的“编辑感海报式个人网站”。

它最强的地方不在某一个动画库，而在以下三点：

- 用“杂志分刊 + 章节叙事”替代常规作品集模块化排版
- 用海报字体、剪贴插画、半调纹理、贴纸感素材建立强人格
- 用轻量但精确的 `transform / opacity / filter` 动效，让每一段都有独立气质

## 3. 整体视觉风格拆解

### 3.1 风格关键词

- Editorial portfolio
- Magazine issue narrative
- Poster layout
- Dark paper texture
- Halftone collage
- Sticker cutout graphics
- Kinetic typography
- Polished brutalism
- Bilingual CN/EN mix

### 3.2 视觉特征

- 深黑背景，不是纯功能型后台黑，而是带纸张感、噪点感的展示黑
- 版式有强烈海报排版倾向，大字、分栏、编号、说明文字并存
- 页面不是普通“项目列表”，而是按 `Issue 02 / 03 / 04` 的章节叙事推进
- 插画偏剪贴画、拼贴画、半调印刷风，不走写实或 3D 商业插画路线
- 主色非常克制，以黑白灰为骨架，再用红、黄、青蓝做局部击穿
- 字体冲突是刻意设计的一部分：正文克制，标题夸张，悬停后甚至换人格

### 3.3 推荐复刻配色

- 背景黑：`#020202`
- 纸感浅色：`#F5F1E8`
- 强调红：`#EF2E35`
- 强调黄：`#FFD84D`
- 冷青蓝：`#7FE7FF`
- 正文字：`#F3F3F3`
- 次级字：`rgba(255,255,255,0.68)`

### 3.4 推荐字体方向

- 正文：`Manrope`、`Inter Tight`、`Space Grotesk`
- 主标题：`Archivo Black`、`Anton`
- 夸张展示字：`Bangers`、`Sigmar`、`Bowlby One SC`、`Changa One`

## 4. 网站实际使用的动画类型

## 4.1 首屏加载动画

- `LOADING` 文案存在轻微脉冲呼吸效果
- 作用：避免首屏静止，给后续 hero 入场建立节奏
- 机制：CSS `@keyframes`，低成本循环，不依赖 JS

## 4.2 首屏蜘蛛掉落

- 首屏出现“蜘蛛整体下坠”的入场效果
- 作用：用一个生物化元素打破海报页面的静态感
- 机制：CSS 入场关键帧，控制位移与透明度

## 4.3 首屏贴纸翻页

- 站点引入了 `/vendor/peel.js`
- Hero 核心贴纸不是假效果，而是显式使用 `Peel.js`
- 作用：制造“撕贴纸 / 翻页 / 掀角”的实体感，是首页记忆点之一
- 机制：`Peel.js + 自定义 peel path + 阴影配置`

## 4.4 Hero 海报抬升与轻微 3D 倾斜

- Hero 主卡片不是平面静态块，而是带 `translate3d / rotate / rotateX / rotateY / scale`
- 作用：让中心海报更像悬浮物，而不是普通图片容器
- 机制：CSS 变量驱动，JS 根据滚动状态或场景状态更新

## 4.5 向下滑动提示动画

- Hero 底部滚动提示点是循环下落
- 作用：引导继续浏览，弱提示，不抢视觉焦点
- 机制：CSS 无限循环关键帧

## 4.6 顶部导航延迟出现

- 导航不是一开始就强存在，而是离开 Hero 后再淡入上移显示
- 作用：让首屏更像封面，导航退居次要位置
- 机制：`opacity + translateY`，通常由滚动状态切换 class

## 4.7 Name Deconstruction 区逐行悬停变化

- 名字拆解区每一行不是统一 hover，而是单独定义字体、颜色、描边、阴影、偏移和倾斜
- 作用：把名字做成人格分裂式视觉实验，而不是普通文字特效
- 机制：每行独立 CSS 变量，hover 后切换不同视觉人格

## 4.8 About 区“假 AI 控制台”切换

- 这里的重点不是气泡对话，而是“问题按钮 + 回答面板 + 输入提问”式控制台交互
- 作用：让自我介绍更像体验型组件，而不是静态段落
- 机制：原生 JS 控制状态切换，动效以淡入、位移为主

## 4.9 Skill Universe 节奏入场

- 中心插画周围的技能徽章不是一次性全出现
- 仓库里存在顺序控制数组，可判断为分批、按序 reveal
- 作用：增加内容分层感，避免中段信息一次性轰炸
- 机制：JS 顺序调度 + `transform / opacity`

## 4.10 项目卡片到详情弹层的复合转场

- 项目详情不是普通抽屉
- 结构中出现 `front / back / mirror / proof-sheet` 等命名
- 作用：让项目详情更像证据板、翻面卡、审阅页，而不是标准详情弹窗
- 机制：多层容器 + 翻面/展开/延迟收束的复合转场

## 5. 它没有重度使用什么

- 不是以 `GSAP ScrollTrigger` 为主的站点
- 不是以 `Framer Motion` 为主的站点
- 不是以 `Three.js / WebGL` 为核心的站点
- 不是以复杂时间轴堆满全站的站点

结论：
它更接近“高审美前端手工站”，而不是“动画框架炫技站”。

## 6. 怎么复刻这种风格

## 6.1 先复刻语法，不要先抄画面

应复刻的是：

- 章节叙事
- 海报式排版
- 拼贴素材语言
- 标题人格化 hover
- 中段技能宇宙
- 项目弹层的非标准展开方式

不建议直接复用：

- 同款蜘蛛
- 同款扩音器/人物插画
- 同款文案结构
- 同款章节名称

## 6.2 最稳的复刻路径

### 第一步：搭页面骨架

- Hero Sticky 封面
- Name Deconstruction
- About Console
- Skill Universe
- Selected Projects
- Contact Poster

### 第二步：搭氛围层

- 全站深色底
- 细网格纹理层
- 噪点层
- 局部 radial 光晕层
- 贴纸阴影层

### 第三步：只做四类动画

- `opacity`
- `transform`
- `filter`
- `clip-path / peel`

### 第四步：最后再加个性段落

- 名字拆解每行独立人格
- 技能徽章顺序出现
- 项目卡翻面详情
- 联系页做收尾海报

## 6.3 技术实现建议

如果用 Vue 3 复刻，建议：

- 框架：`Vue 3 + Vite`
- 动画主力：原生 CSS + 原生 JS 状态控制
- 特殊翻页：`Peel.js` 或自写 `clip-path` 简化版
- 滚动章节：`position: sticky` + CSS 变量
- 节奏 reveal：`IntersectionObserver`

不要上来就做：

- 大量 `top/left` 动画
- 复杂滚动劫持
- 全站无限动画
- 过长的 700ms 以上交互动效

## 7. 关键模块复刻方法

## 7.1 Hero 复刻

- 页面首屏高度拉长到 `160vh ~ 200vh`
- 内层主舞台 `sticky`
- 中心海报使用 `translate3d + rotateX + rotateY + scale`
- 中间贴纸用 `Peel.js` 或 `clip-path` 做折角
- 底部加入下滑提示点动画

## 7.2 名字拆解区复刻

- 每行一个字母或单词解释
- 每行维护独立变量：
  - hover font
  - hover fill
  - hover stroke
  - hover shadow
  - hover skew
  - hover drift
- hover 不做统一规则，要做“每一行都像另一个人格”

## 7.3 Skill Universe 复刻

- 中央主视觉固定
- 四周徽章绝对定位
- 徽章做成贴片，不要做成普通 tag
- 用顺序数组控制 stagger reveal

## 7.4 项目区复刻

- 卡片封面必须有项目人格，不要统一缩略图模板
- hover 只做轻抬升、局部发光、标题强调
- 点击后进入非标准 modal
- modal 内部可以采用 front/back 两层结构

## 8. 可直接给 AI 的提示词

## 8.1 长版网页生成提示词

```text
做一个个人作品集首页，不要 SaaS 模板感，不要通用 agency 风格。

视觉方向：
editorial poster portfolio, dark paper texture, magazine issue narrative, halftone collage, sticker cutout graphics, brutalist but polished, bilingual Chinese and English, cinematic black background, off-white paper accents, sharp red/yellow/cyan highlights, experimental typography with strong contrast between a clean sans body font and playful display fonts.

结构要求：
1. Sticky hero with a poster card in the center
2. A peel / folded sticker interaction on the hero card
3. A name deconstruction section where each letter has its own hover personality, font, color, stroke, and drift motion
4. An About section styled like an AI prompt console with question chips and an answer panel
5. A Skill Universe section with a central illustration and floating tool badges arranged around it
6. A Selected Projects section with highly art-directed project cards, each card having a unique cover composition instead of generic thumbnails
7. A project detail modal with a front/back feel, not a normal drawer
8. A Contact section that feels like a closing poster, bold and memorable

动效要求：
- Use mostly transform, opacity, and filter
- Add a subtle loading pulse
- Add a scroll hint with a looping drop dot
- Add staged reveal between sections
- Add slight 3D lift/parallax to the hero poster
- Add staggered entrance for floating skill badges
- Respect prefers-reduced-motion
- Keep interaction responsive, avoid long sluggish animations

避免：
- 不要紫色默认审美
- 不要玻璃拟物模板风
- 不要普通卡片栅格博客风
- 不要千篇一律的 developer portfolio
```

## 8.2 短版风格关键词

```text
editorial portfolio, issue-based storytelling, poster layout, dark textured background, halftone collage, sticker graphics, kinetic typography, brutalist chic, bilingual CN/EN, cutout illustrations, experimental but polished, art-directed project cards, subtle parallax, peel-sticker hero, cinematic contact poster
```

## 8.3 像它但不撞脸的改写方向

```text
保留 editorial issue 章节叙事、海报式黑底排版、名字人格化 hover、技能宇宙、项目翻面详情弹层这套方法论，但不要复用蜘蛛、扩音器、同款拼贴人物和同款文案。把视觉母题改成机械手、旧相机、金属标签、工业印刷纸张和胶片边框，让整体更像独立设计总监的实验型作品集，而不是直接临摹原站。
```

## 9. 复刻时的注意事项

- 先做结构和气质，再做复杂交互
- 动画尽量使用 `transform` 和 `opacity`
- 所有滚动相关特效都要兼容 `prefers-reduced-motion`
- 移动端不要保留桌面端全部悬停逻辑
- 重要信息不能只依赖 hover 暴露
- 项目封面一定要做差异化，否则会失去这个风格最核心的“作品人格”

## 10. 总结

`eiddie.me` 的价值不在“用了什么神秘动画库”，而在于它把个人作品集做成了一本会动的视觉杂志。

真正应该复刻的是：

- 章节叙事方式
- 海报式视觉语言
- 标题人格化动效
- 贴纸/拼贴的材质感
- 项目详情的非标准表达

如果只抄黑底、大字和几张插画，最后只会得到一个“看起来像创意站”的普通页面；只有把章节、气质、字体冲突和动效节奏一起复刻，才会接近它的完成度。
