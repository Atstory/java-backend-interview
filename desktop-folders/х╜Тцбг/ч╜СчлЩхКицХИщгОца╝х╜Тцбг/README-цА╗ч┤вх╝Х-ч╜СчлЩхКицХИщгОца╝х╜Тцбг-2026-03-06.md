## 六、当前这套资料的核心价值
这一整套资料，核心不是教你“堆特效”，而是帮你建立一套更稳定的方法：
- 先定目标
- 再定风格
- 再定世界观
- 再定动效分层
- 再定交互手感
- 最后才写代码

这套顺序如果稳定下来，以后你做类似网站会快很多，也更不容易跑偏。
