# 网站动效提示词模板（场景版）

## 适用说明
这份文档专门给你以后复用，针对 3 类最常见的网站场景：
- AI 产品官网
- 个人作品集
- 科技公司官网

每类我都给你：
- 风格方向
- 动效重点
- 提示词模板
- 负面约束

你以后只需要替换品牌名、产品名、主色、模块内容，就可以直接拿去用。

---

## 一、AI 产品官网

### 1. 风格方向
AI 产品官网适合的气质通常是：
- 理性
- 克制
- 高级
- 智能感
- 冷静
- 未来感
- 有秩序但不冰冷

推荐意象：
- 神经网络
- 数据流
- 能量核心
- 意识唤醒
- 智能协同
- 认知扩展
- 维度展开

推荐配色：
- 深黑
- 深蓝
- 蓝紫
- 青蓝
- 少量冷白

### 2. 动效重点
AI 官网的动效重点不应该是“炫”，而应该是：
- 体现智能流动
- 体现系统协同
- 体现精密与秩序
- 体现输入、计算、输出的过程感

建议动效层：
- 背景层：低频粒子场、数据网格、星尘雾化
- 主体层：能量核心、神经节点、动态几何体
- 内容层：模块切换、卡片浮动、滚动推进

### 3. 提示词模板
```text
请帮我设计并实现一个 AI 产品官网首页，整体风格要高端、克制、理性、未来感强，像一家真正做前沿智能产品的品牌官网，而不是普通 SaaS 模板站。

视觉风格要求：
1. 主色调为深黑、深蓝、蓝紫、青蓝、少量冷白。
2. 视觉意象围绕神经网络、数据流、能量核心、认知扩展展开。
3. 整体氛围要安静、精密、有秩序、有科技含量，不要浮躁，不要游戏化。

动效要求：
1. 背景使用 Three.js 的全屏 WebGL 粒子系统，表现低频数据宇宙和空间深度。
2. Hero 区域需要一个可交互的“智能核心”视觉主体，可以是粒子能量体、网络节点球或可形变几何体。
3. 鼠标移动时，背景和主体都要有轻微视差和缓动反馈。
4. 滚动时各 section 需要有推进式叙事感，像系统能力被逐层展开。
5. 卡片、标题、模块切换需要有细腻的出现与过渡动画，节奏要克制。

交互要求：
1. 所有交互都必须平滑、有惯性，不要硬跟随。
2. 点击反馈要像系统被激活，而不是普通按钮动画。
3. 动画不能影响阅读效率，内容依然要清晰。

工程要求：
1. 使用 Three.js + GSAP。
2. 模块分离：背景层、Hero 智能核心层、内容层。
3. 需要考虑性能优化和移动端降级。
4. 输出完整可运行代码，不要只给思路。

负面约束：
- 不要廉价赛博朋克
- 不要霓虹乱闪
- 不要像通用 SaaS 模板
- 不要夸张弹跳
- 不要过度装饰
```

### 4. 额外补强词
如果你想更像“AI 公司”，可以额外补这些词：
- inference
- orchestration
- cognition
- intelligence layer
- model routing
- knowledge flow
- agent collaboration
- semantic field

## 二、个人作品集

### 1. 风格方向
个人作品集和企业官网不同，重点不是“权威”，而是：
- 个性
- 审美
- 记忆点
- 叙事感
- 作品呈现力
- 独特但不乱

推荐气质：
- 高级
- 前卫
- 极简
- 神秘
- 艺术化科技感
- 有作者人格

推荐意象：
- 数字展厅
- 交互装置
- 意识空间
- 档案馆
- 星空画廊
- 时间轴宇宙

### 2. 动效重点
作品集最重要的是两件事：
- 首页有记忆点
- 作品展示时不喧宾夺主

建议动效结构：
- 首屏用一个强视觉锚点吸引注意
- 项目列表用轨道、时间轴、星图、空间卡片等形式组织
- 鼠标交互突出“探索感”而不是“功能感”

### 3. 提示词模板
```text
请帮我设计并实现一个高端个人作品集网站首页，整体风格要兼具未来感、艺术感和技术感，像一个数字展厅，而不是普通简历模板站。

视觉风格要求：
1. 气质要独特、有记忆点，但依然高级、克制、干净。
2. 画面意象可以围绕深空、意识空间、数字展厅、时间轨道、交互装置展开。
3. 首页需要有一个强视觉锚点，用来承载作者风格和品牌感。

动效要求：
1. 背景可以使用 Three.js 的粒子宇宙、空间雾层或抽象能量场。
2. Hero 区域需要一个独特的动态主体，例如粒子雕塑、能量球、空间装置或抽象几何体。
3. 项目展示区不要做成普通卡片堆叠，建议使用时间轴、空间节点、轨道式布局或可探索画廊布局。
4. 滚动体验要像在浏览一个数字展馆，具备轻微纵深感和叙事推进感。
5. 鼠标 hover 和点击反馈要有探索感、吸附感和呼吸感。

交互要求：
1. 动画节奏不要过快，保持优雅和高级。
2. 作品内容本身要始终清晰，不能被背景特效盖住。
3. 页面风格要体现作者人格，但不要过度炫技。

工程要求：
1. 使用 Three.js + GSAP。
2. 结构清晰，便于后续替换作品数据。
3. 提供完整可运行代码，并考虑移动端简化方案。

负面约束：
- 不要普通简历模板风
- 不要 Dribbble 式廉价炫技拼贴
- 不要五颜六色乱闪
- 不要让动效压过作品内容
- 不要过多小组件堆砌
```

### 4. 额外补强词
如果你想让作品集更“作者化”，可以加：
- auteur
- exhibition
- narrative interface
- spatial storytelling
- digital sculpture
- archive of experiments
- interactive gallery

## 三、科技公司官网

### 1. 风格方向
科技公司官网要比作品集更稳，比 AI 产品官网更偏品牌和企业信任感。

重点气质：
- 专业
- 稳定
- 高端
- 精密
- 品牌化
- 国际化
- 有未来感但不过分实验性

推荐意象：
- 未来基础设施
- 数字中枢
- 全球网络
- 工业级智能
- 系统协同
- 可信技术平台

推荐配色：
- 深蓝黑
- 石墨灰
- 冷白
- 电青点缀
- 少量金属质感色

### 2. 动效重点
科技公司官网的动效应该更服务于“信任感”和“品牌表达”：
- 背景可有空间层次，但不要太艺术化
- 模块切换要稳
- 数据、架构、能力展示要清晰
- 动画存在感适中，不能抢业务信息

### 3. 提示词模板
```text
请帮我设计并实现一个高端科技公司官网首页，整体风格要专业、稳重、未来感适中，像一家有核心技术和全球业务能力的科技企业官网。

视觉风格要求：
1. 主色调为深蓝黑、石墨灰、冷白，可少量加入电青或蓝紫作为点缀。
2. 画面气质要国际化、专业、可信、精密，不要过度实验化，不要游戏化。
3. 可以有科技感空间背景，但整体必须服务于品牌表达和业务信息传达。

动效要求：
1. 背景需要轻量的空间层次感，可使用低密度粒子、网格、光流或数字地平线。
2. Hero 区域可以有一个抽象技术核心视觉，如能量中枢、网络结构、数据装置，但不要过于艺术化。
3. 页面滚动时，各业务模块、能力模块、案例模块要有清晰且克制的进入动效。
4. section 切换应具备轻微纵深感，但不能影响阅读和可用性。
5. 数据、指标、架构图、能力标签出现时需要有专业、稳定、节制的动态呈现。

交互要求：
1. 鼠标反馈要轻，不要夸张。
2. 整体交互更偏企业级产品体验，而不是实验艺术体验。
3. 动效要增强品牌质感和可信度。

工程要求：
1. 使用 Three.js + GSAP 或其他合适方案。
2. 动效参数可配置，方便后续品牌升级。
3. 要考虑 SEO、首屏性能和移动端兼容。
4. 输出完整可运行代码。

负面约束：
- 不要游戏化
- 不要过度赛博朋克
- 不要炫技压过业务信息
- 不要过重的 GPU 特效
- 不要廉价模板感
```

### 4. 额外补强词
如果你想让它更像“成熟科技企业”，可以补这些词：
- infrastructure
- trusted platform
- scalable systems
- precision engineering
- enterprise-grade
- reliability
- global network
- digital backbone

## 四、三类场景怎么选词

### 如果你想更“产品化”
优先用：
- 智能
- 协同
- 推理
- 数据流
- 神经网络
- 认知扩展

### 如果你想更“作者化”
优先用：
- 展厅
- 叙事
- 档案馆
- 装置
- 意识空间
- 数字雕塑

### 如果你想更“企业化”
优先用：
- 基础设施
- 平台
- 可信
- 稳定
- 精密
- 全球网络

---

## 五、最实用的组合写法
以后你可以直接用这句公式：

```text
请帮我做一个 [网站类型] 首页，气质偏 [产品化 / 作者化 / 企业化]，整体风格要 [3~5个基调词]，视觉意象围绕 [2~4个空间意象]，页面动效分为背景层、主体层、内容层三部分；所有交互都要有缓动、惯性和克制感；不要 [3~5个负面词]；请输出完整可运行代码，并考虑性能优化与移动端降级。
```

---

## 六、我的建议
如果你以后自己写提示词，最稳的办法是：
- 先确定网站类型
- 再确定气质归属：产品化 / 作者化 / 企业化
- 再写视觉世界观
- 再写动效层级
- 最后补负面约束

这样写出来的结果，基本都会比“做一个炫酷科技感官网”强很多。
