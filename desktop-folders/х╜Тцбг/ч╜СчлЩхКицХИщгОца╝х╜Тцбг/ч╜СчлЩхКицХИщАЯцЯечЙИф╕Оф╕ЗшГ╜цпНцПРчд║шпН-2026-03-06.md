# 网站动效速查版与万能母提示词

## 一、速查版
以后你做类似风格的网站，先不要急着写代码，先快速过下面这 8 条。

### 1. 先定目标
先想清楚：
- 这是品牌站、产品站、作品集，还是活动页
- 首页第一目标是什么
- 用户第一眼应该记住什么

如果这一步不清楚，后面动效越多越容易乱。

### 2. 先定气质
先选页面属于哪种大方向：
- 产品化
- 作者化
- 企业化

再选审美方向：
- 暗黑极简风
- 苹果发布会风
- 科幻实验室风

### 3. 先定世界观
不要只写“科技感”。
要写成：
- 深空
- 星尘
- 能量体
- 数据流
- 数字展厅
- 时间裂隙
- 未来实验室

### 4. 先定动效分层
首页动效至少分三层：
- 背景层：粒子、雾化、空间深度
- 主体层：Hero 主视觉、能量球、产品核心
- 内容层：标题、卡片、模块进入

如果要再高级一点，再加：
- 切换层：section 的纵深推进

### 5. 先定交互手感
交互要写清：
- 鼠标跟随必须有缓动和惯性
- hover 要轻，不要炸
- 点击要有脉冲、觉醒、重组这种反馈
- 动画节奏要慢、克制、顺滑

### 6. 先定技术要求
推荐直接写：
- 使用 `Three.js + GSAP`
- 背景用 WebGL，不要普通 CSS 假装
- 模块拆分清晰
- 移动端降级
- 限制像素比
- 页面隐藏时暂停渲染

### 7. 一定写负面约束
这是最容易被忽略但最重要的部分。

常用写法：
- 不要廉价赛博朋克
- 不要霓虹乱闪
- 不要高频闪烁
- 不要硬跟随
- 不要模板站味道
- 不要动效压过内容
- 不要 GPU 压力过大

### 8. 最后再看是否值得做
做完后问自己：
- 页面是高级，还是只是热闹
- 动效是在服务内容，还是抢内容
- 用户会记住什么
- 如果删掉 30% 动效，会不会更好

如果答案是“会更好”，那通常就是做多了。

## 二、最短公式
以后赶时间，就直接套这句：

```text
请帮我做一个 [网站类型] 首页，整体气质偏 [产品化 / 作者化 / 企业化]，审美方向偏 [暗黑极简风 / 苹果发布会风 / 科幻实验室风]，视觉意象围绕 [深空 / 星尘 / 能量体 / 数据流 / 数字展厅 / 时间裂隙]，页面动效分为背景层、主体层、内容层三部分，所有交互都必须有缓动、惯性和克制感；请使用 Three.js + GSAP，考虑性能优化与移动端降级；不要廉价赛博朋克、不要霓虹乱闪、不要硬跟随、不要模板站味道；请输出完整可运行代码。
```

## 三、万能母提示词
这份是以后最值得反复复用的一版。

你只需要替换掉方括号里的内容，就可以直接给 AI 用。

```text
请你作为资深前端视觉工程师和交互设计师，帮我设计并实现一个高质量的网站首页。

一、项目定位
- 网站类型：[AI 产品官网 / 科技公司官网 / 个人作品集 / 品牌官网 / 发布页]
- 首页目标：[品牌表达 / 产品转化 / 建立信任 / 展示作品 / 活动传播]
- 用户第一眼需要记住的核心点：[一句话概括]

二、风格方向
- 气质关键词：[克制 / 深邃 / 高级 / 理性 / 神秘 / 未来感 / 实验性 / 企业感 / 作者感]
- 审美方向：[暗黑极简风 / 苹果发布会风 / 科幻实验室风]
- 视觉意象：[深空 / 星尘 / 能量体 / 数据流 / 数字展厅 / 时间裂隙 / 未来研究设施 / 神经网络]
- 配色方向：[黑 / 炭黑 / 深蓝 / 靛蓝 / 紫 / 青 / 冷白]

三、页面结构
请将首页动效拆成以下层次并分别设计：
1. 背景层：负责空间氛围、深度、粒子、雾化、光流或宇宙感
2. 主体层：负责 Hero 主视觉，例如能量球、产品核心、几何装置、粒子主体
3. 内容层：负责标题、副标题、按钮、卡片、模块进入与信息表达
4. 切换层（如需要）：负责 section 之间的纵深推进、穿越感或叙事滚动

四、动效要求
1. 背景层必须有空间深度，但不能抢正文内容。
2. 主体层必须是页面的视觉锚点，要有呼吸感、流动感、脉冲感或形态演化感。
3. section 切换如果存在，需要有叙事感、推进感和纵深感，而不是普通滚动。
4. 动画节奏整体偏慢、克制、顺滑，不要浮躁。
5. 页面要有高级感、品牌感、未来感，但不要显得廉价或游戏化。

五、交互手感要求
1. 鼠标跟随必须使用缓动、lerp 或 easing，不允许硬跟随。
2. hover 反馈必须轻微、克制、有吸附感或呼吸感，不要夸张。
3. 点击反馈要像能量脉冲、状态觉醒、结构重组，而不是普通缩放。
4. 所有交互都要有惯性和细腻过渡。

六、技术要求
1. 技术栈优先使用 `Three.js + GSAP`。
2. 背景层优先使用 WebGL，不要只用普通 CSS 敷衍。
3. 代码结构清晰，模块分离，至少拆分为背景层、主体层、切换层、配置层。
4. 参数可配置，包括粒子数量、颜色、动效强度、速度、交互幅度。
5. 输出完整可运行代码，不要只给概念。

七、性能要求
1. 限制 `renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))`。
2. 桌面端与移动端粒子数量分级处理。
3. 页面不可见时暂停渲染或降低更新频率。
4. 避免高频重型 DOM 操作。
5. 优先保证流畅度，再追求高保真。

八、内容表达要求
1. 首页必须清楚表达“我是谁 / 我做什么 / 为什么值得看 / 下一步做什么”。
2. 动效必须服务内容，不允许喧宾夺主。
3. 标题、副标题、CTA 层级必须清晰。

九、负面约束
请严格避免以下问题：
- 不要廉价赛博朋克
- 不要霓虹乱闪
- 不要高频闪烁
- 不要夸张弹跳
- 不要硬跟随
- 不要动效压过内容
- 不要模板站味道
- 不要游戏登录页感
- 不要过度装饰
- 不要 GPU 压力过大

十、输出要求
请按以下顺序输出：
1. 先给出整体方案拆解
2. 再给出模块划分
3. 再给出完整代码
4. 再给出性能优化点
5. 再给出移动端降级策略
6. 关键代码都加清晰注释
```

## 四、母提示词的三种常用改法
你以后通常只需要改这三块。

### 1. 改网站类型
比如改成：
- AI 产品官网
- 个人作品集
- 科技公司官网
- 发布会页面

### 2. 改审美方向
比如改成：
- 暗黑极简风
- 苹果发布会风
- 科幻实验室风

### 3. 改视觉意象
比如改成：
- 深空
- 数据流
- 神经网络
- 数字展厅
- 时间裂隙
- 研究设施

这三块一换，基本就能快速生成一版新的高质量提示词。

## 五、三个直接可用的简化母提示词

### 1. 稳妥商业版
```text
请帮我做一个高端未来感品牌网站首页，整体风格克制、深邃、高级、流畅，审美方向偏苹果发布会风，背景有轻量空间层次，Hero 有强视觉主体，滚动像镜头推进；使用 Three.js + GSAP，实现完整可运行代码，并考虑性能优化与移动端降级；不要廉价赛博朋克、不要模板站味道、不要动效压过内容。
```

### 2. 创意展示版
```text
请帮我做一个具有未来实验室气质的网站首页，视觉意象围绕深空、粒子装置、能量核心、时间裂隙展开，审美方向偏科幻实验室风；背景、Hero、section 切换都要有空间感和探索感，交互必须顺滑、克制、有惯性；请输出完整代码，并控制性能与移动端体验。
```

### 3. 极简高级版
```text
请帮我做一个暗黑极简风的网站首页，整体气质安静、克制、高级、冷静，背景只保留轻微空间粒子与雾感，主体强调品牌感与视觉锚点，动画以淡入、轻推、缓慢缩放为主；不要夸张粒子、不要高频闪烁、不要硬跟随；请输出可运行代码并保持结构清晰。
```

## 六、最后的实用建议
以后你真的要开做，最稳的顺序是：
- 先用“最短公式”快速出一版
- 不满意再用“万能母提示词”细化
- 真的要落地时，再补场景、审美、负面约束和性能要求

如果你只想快，先用短公式。
如果你想准，直接用母提示词。

这一份文档，后面就可以当你自己的“首页动效总开关模板”。
