# 网站风格词库（审美方向版）

## 适用说明
这份文档补的是“审美方向”，不是业务场景。

也就是说：
- 上一份文档解决“你做什么网站”
- 这一份文档解决“你想让它长成什么气质”

这次整理 3 个最常用、也最容易出高级感的方向：
- 暗黑极简风
- 苹果发布会风
- 科幻实验室风

以后你可以把“场景”与“审美方向”组合使用。
例如：
- AI 产品官网 + 苹果发布会风
- 个人作品集 + 科幻实验室风
- 科技公司官网 + 暗黑极简风

---

## 一、暗黑极简风

### 1. 核心气质
这个方向的重点不是“炫”，而是：
- 克制
- 干净
- 冷静
- 高级
- 留白
- 精准
- 安静
- 极简但有压迫感

它适合：
- 高端品牌站
- AI 产品官网
- 个人品牌首页
- 设计感很强的作品集

### 2. 视觉关键词
可以直接用这些词：
- 深黑背景
- 微弱辉光
- 冷白文字
- 极简排版
- 强留白
- 低饱和点缀色
- 空气感
- 克制光感
- 结构清晰
- 安静的未来感

### 3. 配色建议
典型搭配：
- 主背景：黑色、炭黑、深灰黑
- 文字：冷白、灰白
- 点缀：青蓝、蓝紫、银灰
- 光感：只保留极弱发光，不要大面积霓虹

### 4. 动效风格
暗黑极简风的动效必须“少而准”。

建议写法：
- 背景有极轻微粒子漂浮或空间雾感
- 大多数元素以淡入、上浮、轻推、遮罩显现为主
- 鼠标交互要弱反馈，不要夸张吸附
- section 切换应平稳、缓慢、静音感强
- 动画更像“呼吸”，不是“表演”

### 5. 提示词模板
```text
请帮我设计并实现一个暗黑极简风的网站首页，整体风格要克制、冷静、高级、安静，有强留白和品牌感，不要过度炫技。

视觉要求：
1. 以深黑、炭黑、冷白为主色，少量使用青蓝或蓝紫作为点缀。
2. 画面要干净、极简、精确，有空气感和秩序感。
3. 不要复杂纹理，不要太多装饰元素，不要大面积炫光。

动效要求：
1. 背景只保留非常轻微的空间粒子或雾化层次。
2. 元素出现以淡入、遮罩显现、轻微位移和缓慢缩放为主。
3. 鼠标交互要克制，只做轻微视差和弱反馈。
4. section 切换要平稳、安静、有高级感，不要夸张。

交互要求：
1. 所有动画节奏偏慢。
2. 不要跳跃感，不要高频闪烁。
3. 页面整体像高端品牌官网，而不是特效展示页。

负面约束：
- 不要廉价赛博朋克
- 不要霓虹乱闪
- 不要过度粒子
- 不要夸张弹跳
- 不要花哨装饰
```

### 6. 负面词补充
暗黑极简风最怕这些问题：
- 太空了但不高级
- 太黑了但没层次
- 太简了像没设计
- 动效太多破坏安静感

所以建议常加：
- 不要空洞
- 不要廉价
- 不要只有黑底大字
- 不要为了极简牺牲层次

## 二、苹果发布会风

### 1. 核心气质
这个方向不是“苹果官网复制风”，而是它背后的表达方式：
- 精准
- 高级
- 流畅
- 极强产品聚焦
- 节奏控制优秀
- 视觉与叙事高度统一

它适合：
- AI 产品官网
- 硬件产品官网
- SaaS 产品发布页
- 企业品牌首页

### 2. 视觉关键词
你可以直接写：
- 产品主角化
- 大面积留白
- 层次明确
- 叙事式滚动
- 近物展示
- 精密材质感
- 平滑过渡
- 镜头推进感
- 现代极简
- 高级商业视觉

### 3. 配色建议
苹果发布会风不一定只能白底，也可以深色版本。

典型配色：
- 背景：白、浅灰、炭黑、深灰
- 字体：高对比黑白
- 点缀：产品本身的主色
- 光感：柔和、干净、控制精准

### 4. 动效风格
这个风格的关键不是粒子，而是：
- 叙事推进
- 镜头感
- 产品作为视觉中心
- 动画服务讲述

建议写法：
- Hero 区产品或核心视觉要像“发布会开场主角”
- 滚动时像镜头推进，不像页面翻页
- 组件进入和切换要极其丝滑
- 重点信息要一层层揭示
- 动效存在感很强，但不喧闹

### 5. 提示词模板
```text
请帮我设计并实现一个带有苹果发布会风格气质的网站首页，要求整体高级、精准、流畅，强调产品主角感和叙事式滚动体验。

视觉要求：
1. 页面排版简洁，层次非常清晰，产品或核心视觉必须成为首页绝对主角。
2. 画面要有高端商业视觉质感，留白充足，信息表达干净。
3. 可以使用深色或浅色方案，但整体必须统一、精确、克制。

动效要求：
1. 滚动体验要像镜头推进和内容揭示，而不是普通网页滚动。
2. 核心视觉元素需要有轻微的空间感、缩放感、推进感。
3. 每一屏内容出现都要有明确节奏，像发布会讲述一个完整故事。
4. 动画需要丝滑、稳定、精确，不要过多炫技型粒子特效。

交互要求：
1. 鼠标交互不宜过重，应以精致的过渡和细节反馈为主。
2. 产品图、核心模块、数据点切换时需要非常顺滑。
3. 页面要突出品牌感、可信度和高级商业质感。

工程要求：
1. 可以使用 Three.js、GSAP 或更轻量的组合，但要以叙事和展示为中心。
2. 保证首屏性能与整体流畅度。
3. 输出完整可运行代码。

负面约束：
- 不要像普通发布会 PPT 网页
- 不要粒子特效泛滥
- 不要花哨赛博朋克
- 不要复杂到压住产品主体
- 不要动画比内容还吵
```

### 6. 负面词补充
苹果发布会风最怕的是：
- 只有大标题，没有叙事
- 动画多但没有镜头感
- 看起来像普通营销页
- 没有产品主角感

所以建议补：
- 强调镜头推进感
- 强调主视觉聚焦
- 强调节奏控制
- 强调内容揭示顺序

## 三、科幻实验室风

### 1. 核心气质
这个方向更偏“未来研究机构 / 数字实验室 / 前沿技术装置”。

核心气质是：
- 神秘
- 深邃
- 实验性
- 智性
- 非现实感
- 空间感
- 强探索欲
- 未来研究设施感

它适合：
- AI 项目官网
- 前沿科技展示页
- 创意作品集
- 实验性产品首页

### 2. 视觉关键词
可直接用：
- 数字实验室
- 深空研究站
- 能量核心
- 粒子装置
- 数据星图
- 量子场
- 维度裂隙
- 抽象几何结构
- 神经拓扑
- 研究设施

### 3. 配色建议
- 深黑
- 深蓝黑
- 靛蓝
- 冷紫
- 青色
- 冷白
- 少量荧光边缘高光

注意：
这个方向允许比前两者更有实验感，但不能变成廉价赛博朋克。

### 4. 动效风格
这个方向的动效可以更大胆，但要有“研究装置逻辑”。

建议写法：
- 背景是深空粒子场、空间雾、拓扑点云或抽象能量流
- Hero 是一个实验装置、能量核、几何粒子体或拓扑结构
- 鼠标靠近时，主体像被激活、扫描、重构
- 点击后可进入形态切换、结构展开、状态觉醒
- section 切换像穿越不同实验舱或研究模块

### 5. 提示词模板
```text
请帮我设计并实现一个科幻实验室风格的网站首页，整体氛围要像未来研究机构、数字实验室或前沿技术装置空间，具有神秘感、空间感和探索感。

视觉要求：
1. 主色调为深黑、深蓝黑、靛蓝、冷紫、青色、冷白。
2. 视觉世界观围绕深空研究站、能量核心、粒子装置、维度裂隙、数据星图展开。
3. 画面要高级、深邃、实验性强，但不能廉价，不能像游戏登录页。

动效要求：
1. 背景使用 Three.js 构建空间粒子场、雾化层或抽象宇宙结构。
2. Hero 区域需要一个强视觉主体，例如实验能量核心、粒子拓扑球、动态几何装置。
3. 主体需要具备呼吸感、波动感、扫描感、结构重组感。
4. 鼠标靠近时要有轻微磁吸、扰动、觉醒式反馈。
5. 点击时可以触发形态切换、结构展开或秩序化演变。
6. 页面 section 切换要有穿越实验舱、进入不同研究模块的感觉。

交互要求：
1. 所有交互都要平滑并带惯性。
2. 动画允许更有探索感，但不能噪音过大。
3. 文案和信息依然要可读，动效不能盖住内容。

工程要求：
1. 使用 Three.js + GSAP。
2. 模块清晰拆分，便于调整动效强度。
3. 考虑性能优化、移动端降级、隐藏页暂停渲染。
4. 输出完整可运行代码。

负面约束：
- 不要廉价赛博朋克
- 不要霓虹灯乱闪
- 不要游戏化 UI
- 不要只有特效没有结构
- 不要视觉噪音太高
```

### 6. 负面词补充
科幻实验室风容易踩的坑：
- 太花哨
- 太多粒子
- 太多故障风/glitch
- 只像“特效演示”而不像“网站”

所以建议加：
- 强调结构化布局
- 强调内容可读性
- 强调品牌感或研究机构感
- 强调克制而非失控

## 四、三种审美怎么选

### 如果你想更稳、更高级、更商业
选：
- 暗黑极简风
- 苹果发布会风

### 如果你想更有记忆点、更有未来实验感
选：
- 科幻实验室风

### 如果你想更偏品牌站
优先：
- 暗黑极简风
- 苹果发布会风

### 如果你想更偏创意首页 / 作品集
优先：
- 科幻实验室风
- 暗黑极简风

## 七、我的建议
如果你以后追求的是“稳定高级”，优先级建议是：
- 第一选择：`苹果发布会风`
- 第二选择：`暗黑极简风`
- 第三选择：`科幻实验室风`

原因很现实：
- 苹果发布会风最容易商业化落地
- 暗黑极简风最容易做得耐看
- 科幻实验室风最容易惊艳，但也最容易做过头

所以：
- 想稳：选前两个
- 想炸场：选第三个
