# 超短版 Cheat Sheet 与个人专用母提示词

## 一、超短版 Cheat Sheet
以后你想做一页有高级感的网站首页，先只看这一页就够了。

### 1. 先定 4 件事
先明确：
- 网站类型：产品站 / 品牌站 / 作品集 / 公司官网
- 页面目标：表达品牌 / 展示作品 / 建立信任 / 转化点击
- 审美方向：暗黑极简 / 苹果发布会 / 科幻实验室
- 视觉意象：深空 / 星尘 / 能量体 / 数据流 / 数字展厅 / 时间裂隙

### 2. 首页永远分层
至少分 3 层：
- 背景层：空间氛围、粒子、雾化、深度
- 主体层：Hero 主视觉、能量球、装置、产品核心
- 内容层：标题、副标题、按钮、卡片、模块信息

要更高级，再加：
- 切换层：section 的纵深推进和叙事过渡

### 3. 高级感的关键不是“炫”
真正重要的是：
- 有主次
- 有节奏
- 有留白
- 有惯性
- 有克制

### 4. 交互必须这样写
- 鼠标跟随必须有缓动，不要硬跟随
- hover 要轻，不要炸
- 点击要有脉冲、觉醒、重组感
- 动画节奏偏慢、顺滑、安静

### 5. 技术要求最少写这些
- 使用 `Three.js + GSAP`
- 背景优先 WebGL
- 模块拆分清晰
- 移动端降级
- 限制像素比
- 隐藏页面暂停渲染

### 6. 负面词一定带上
以后默认都加：
- 不要廉价赛博朋克
- 不要霓虹乱闪
- 不要高频闪烁
- 不要模板站味道
- 不要硬跟随
- 不要动效压过内容
- 不要 GPU 压力过大

### 7. 做完后只问 4 句
- 页面是高级，还是只是热闹？
- 动效是在服务内容，还是抢内容？
- 用户 5 秒内记住什么？
- 删掉 30% 动效会不会更好？

如果最后一题答案是“会”，通常就是做多了。

## 三、你的个人专用母提示词
这一版是按你当前这套偏好专门收敛出来的。

以后你做大多数“高端未来感网站首页”，直接从这版开始改，效率最高。

```text
请你作为资深前端视觉工程师、交互设计师和品牌站架构设计师，帮我设计并实现一个高质量的网站首页。

一、总目标
我想要的不是普通模板站，也不是纯炫技特效页，而是一个真正有高级感、未来感、品牌感的网站首页。

二、默认风格
请默认按以下气质执行：
- 高级
- 克制
- 深邃
- 安静
- 有空间感
- 未来感强
- 不廉价
- 不游戏化

三、默认审美方向
优先按以下方向理解：
- 第一优先：苹果发布会风
- 第二优先：暗黑极简风
- 第三优先：科幻实验室风

也就是说，整体视觉需要兼顾：
- 商业级高级感
- 极简克制的秩序感
- 少量未来实验气质

四、默认视觉意象
请围绕这些意象构建页面：
- 深空
- 星尘
- 能量体
- 数据流
- 时间裂隙
- 数字展厅

五、页面结构要求
请把首页拆成以下层次：
1. 背景层：负责空间氛围、深度、粒子、雾化或微弱光流
2. 主体层：负责 Hero 主视觉，必须有一个强视觉锚点，例如能量球、产品核心、粒子装置或抽象几何体
3. 内容层：负责标题、副标题、按钮、卡片和业务信息，必须清晰可读
4. 切换层：如果有多个 section，请做出纵深推进、叙事展开或镜头感切换

六、动效要求
1. 背景层要有空间感，但不能抢正文。
2. 主体层要有呼吸感、流动感、脉冲感或形态演化感。
3. 页面滚动和 section 切换应有纵深感和推进感，但不要喧宾夺主。
4. 动画节奏必须偏慢、顺滑、克制、安静。
5. 整体观感要像高端科技品牌站，而不是模板页或游戏页。

七、交互手感要求
1. 鼠标跟随必须使用缓动、惯性、lerp 或 easing，不允许硬跟随。
2. hover 反馈要轻，有吸附感、呼吸感、磁性感，但不要夸张。
3. 点击反馈要有能量脉冲、状态觉醒、结构重组的感觉，而不是普通缩放。
4. 所有交互都要自然、平滑、细腻。

八、技术要求
1. 技术栈优先使用 `Three.js + GSAP`。
2. 背景优先使用 WebGL，而不是只用普通 CSS 敷衍。
3. 代码结构清晰，模块拆分明确，至少分为背景层、主体层、切换层、配置层。
4. 参数可配置，包括颜色、粒子数量、速度、交互强度、动效幅度。
5. 输出完整可运行代码，不要只给思路。

九、性能要求
1. 限制 `renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))`。
2. 根据桌面端和移动端分别控制粒子数量。
3. 页面不可见时暂停渲染或降低更新频率。
4. 避免高频重型 DOM 操作。
5. 优先保证稳定流畅，再追求极致特效。

十、内容要求
1. 首页必须清楚表达：我是谁、我做什么、为什么值得继续看、下一步该做什么。
2. 动效必须服务内容，不允许压过信息表达。
3. 标题、副标题、CTA 的层级必须明确。

十一、负面约束
请严格避免：
- 廉价赛博朋克
- 霓虹乱闪
- 高频闪烁
- 夸张弹跳
- 硬跟随
- 模板站味道
- 游戏登录页感
- 特效大于内容
- 满屏粒子乱飞
- GPU 压力过大

十二、输出要求
请按顺序输出：
1. 先给整体方案拆解
2. 再给模块划分
3. 再给完整代码
4. 再给性能优化建议
5. 再给移动端降级方案
6. 每段关键代码都加清晰注释
```
