# 高端未来感网站风格词库与动效提示词模板

## 使用方法
以后你要写类似风格的网站，不要只写“科技感、高级感、炫酷”。

更有效的写法是固定按以下 6 个维度描述：
- 风格基调
- 空间意象
- 动效分层
- 交互手感
- 技术实现
- 负面约束

只要这 6 个维度写清楚，AI 生成结果会稳定很多。

## 一、风格词库

### 1. 基调关键词
适合高端未来感、品牌站、深空风：
- 克制
- 深邃
- 安静
- 冷静
- 神秘
- 高级
- 理性
- 秩序感
- 未来感
- 品牌感
- 非游戏化
- 非模板化

### 2. 空间意象关键词
用来描述画面世界观：
- 深空
- 星尘
- 星云
- 宇宙背景
- 粒子场
- 能量核心
- 光锥
- 时间裂隙
- 维度折叠
- 空间褶皱
- 意识流
- 秩序与混沌
- 数据星海
- 量子脉冲
- 几何神经网络

### 3. 视觉气质关键词
用来限制风格跑偏：
- 高端科技品牌站
- 展厅式首页
- 视觉克制
- 留白充足
- 空气感强
- 有纵深
- 有呼吸感
- 不浮躁
- 不廉价
- 不堆特效

### 4. 配色关键词
适合这类风格的配色表达：
- 深黑
- 炭黑
- 靛蓝
- 蓝紫
- 冷紫
- 青蓝
- 冰青
- 冷白
- 微弱辉光
- 低饱和发光

### 5. 字体与排版关键词
- 几何无衬线
- 紧凑字距的大标题
- 高对比层级
- 大留白
- 轻量副标题
- 科技感但不过度机械
- 标题强识别，正文弱存在感

## 二、负面词库
这部分非常重要，用来防止生成结果变廉价。

### 1. 风格负面词
- 不要廉价赛博朋克
- 不要霓虹灯乱闪
- 不要游戏登录页风格
- 不要酒吧灯牌感
- 不要 PPT 模板风
- 不要过度装饰
- 不要过度炫技

### 2. 动效负面词
- 不要高频闪烁
- 不要夸张弹跳
- 不要硬跟随
- 不要抖动
- 不要过强 blur
- 不要满屏粒子乱飞
- 不要 hover 一惊一乍
- 不要动画节奏过快

### 3. 工程负面词
- 不要把所有逻辑写在一个文件里
- 不要只做普通 2D 粒子背景敷衍
- 不要忽略移动端降级
- 不要忽略性能开销
- 不要为了视觉牺牲可读性

## 三、动效分层模板
以后写提示词，最好按层来描述。

### 1. 背景层
你可以这样写：
- 全屏固定的深空粒子背景
- 使用 WebGL / Three.js，而不是普通 CSS 背景
- 至少两层粒子，形成远近深度
- 粒子缓慢漂浮、旋转、呼吸
- 有轻微雾化和空间感

### 2. 主体层
你可以这样写：
- 首屏需要一个视觉锚点，例如能量球、粒子核心、几何装置
- 主体不是静态图，而是可呼吸、可脉冲、可形变的动态对象
- 鼠标靠近时主体有磁吸、轻微偏转、弹性缩放
- 点击后主体发生形态演化，而不是简单放大

### 3. 页面切换层
你可以这样写：
- section 切换带纵深感
- 使用 translate3d、scale、opacity 做空间过渡
- 切换感像穿越、推进、折叠，不像普通滚动
- 动画偏慢，具有惯性与过渡缓冲

## 四、交互手感模板
这是这类网站是否“高级”的关键。

以后可直接写：
- 鼠标交互必须带惯性和缓动
- 所有跟随都要用 lerp 或 easing，不允许硬跟随
- hover 的反馈要克制，像被吸引，不要突兀
- 点击反馈要像能量脉冲、状态觉醒、结构重组
- 动画节奏偏慢，顺滑，有呼吸感
- 页面整体安静、稳重，不要躁动

## 五、技术约束模板
如果你想让 AI 直接产出更能落地的代码，必须补上这些约束：
- 使用 `Three.js + GSAP`
- 背景必须是 `WebGL` 粒子系统
- 模块拆分为：背景层、Hero 层、Section 切换层
- 需要 `resize` 自适应
- 需要移动端降级
- 限制 `renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))`
- 页面隐藏时暂停渲染
- 输出完整可运行代码，不要只给思路

## 六、通用提示词公式
以后你可以套这个公式：

```text
请帮我设计并实现一个 [网站类型] 首页，整体风格要 [风格基调]，视觉意象是 [空间意象]。

1. 背景层：[背景层描述]
2. 主体层：[主体层描述]

交互要求：
- [交互手感 1]
- [交互手感 2]
- [交互手感 3]

技术要求：
- [技术栈]
- [性能要求]
- [输出形式]

- [不要什么 1]

```

## 七、可直接复用的万能模板

### 模板 A：高端未来感品牌站
```text
请帮我设计并实现一个高端未来感网站首页，整体风格要克制、深邃、安静、有空间感，像高端科技品牌站，而不是游戏官网。

视觉风格要求：
1. 主色为黑色、靛蓝、紫色、青色、少量冷白。
2. 氛围是深空、星尘、能量体、秩序与混沌、时空折叠。
3. 画面要高级、干净、有纵深，不要廉价赛博朋克，不要过度炫光。

动效要求：
1. 背景使用 Three.js 的全屏 WebGL 粒子宇宙，不要普通 2D canvas 连线网格。
2. 至少两层粒子，形成远近深度和轻微漂浮感。
3. Hero 区域需要一个可交互的粒子能量体，具备呼吸感、波动感和轻微脉冲。
4. 鼠标移动时，背景和主体都要有缓动视差，不要硬跟随。
5. 点击主体时要有“觉醒/形态演化”的反馈，不只是缩放。
6. 页面 section 切换要有穿越和推进感，使用 translate3d、scale、opacity 实现纵深过渡。

交互手感要求：
1. 所有交互都必须带惯性和 easing。
2. 动画节奏偏慢、克制、顺滑。
3. 不要抖动、不要高频闪烁、不要夸张弹跳。

工程要求：
1. 使用 Three.js + GSAP。
2. 模块拆分清晰：BackgroundUniverse、HeroEnergyCore、SectionRift。
3. 考虑性能优化：限制 pixelRatio、移动端降级、页面隐藏时暂停渲染。
4. 输出完整可运行代码，并给每个模块加清晰注释。
```

## 八、进阶写法
如果你想让 AI 更稳定，可以把提示词再补上这 4 类约束。

### 1. 品牌调性
- 面向高端用户
- 像技术品牌官网
- 像未来研究机构首页
- 像数字展厅，不像模板站

### 2. 节奏控制
- 首屏动效先慢后稳
- 不要一上来就高强度炫技
- 动效存在感强，但不能干扰阅读

### 3. 信息布局
- 标题区要极简
- 文案不宜太多
- 视觉锚点要集中在 Hero
- 后续 section 要服务于叙事推进

### 4. 可维护性
- 背景、主体、交互、滚动逻辑分离
- 参数集中管理
- 配色、粒子数量、动效强度可配置

## 九、最实用的经验总结
以后你只要记住下面 5 点，提示词基本不会差：
- 先写世界观，不要只写“科技感”
- 再写画面分层，不要只写一个效果
- 再写交互手感，强调缓动、惯性、克制
- 再写技术要求，让结果可落地
- 最后写负面约束，防止跑偏变廉价
